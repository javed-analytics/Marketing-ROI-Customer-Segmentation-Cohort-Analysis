# Methodology — Customer Segmentation

## Objective
Identify customer value concentration to support differentiated marketing and retention strategies.

## Segmentation Metric
Customer value is measured using total spend:

MntTotal = Sum of all product-category purchases per customer

## Segment Thresholds
Customers are segmented using spend percentiles:
- **High Value**: ≥ 80th percentile
- **Mid Value**: 50th–80th percentile
- **Low Value**: < 50th percentile

## Outputs
- Customer count by segment
- Revenue contribution by segment
- Average spend per customer

## Rationale
Percentile-based segmentation adapts to skewed revenue distributions and avoids arbitrary cutoffs.
